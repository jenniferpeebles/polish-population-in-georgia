# Validation checklist

Before publication:

- Confirm every configured ACS variable has the expected Census label.
- Confirm 51 states/D.C. and all 159 Georgia counties.
- Confirm unique GEOIDs and no impossible negative estimates.
- Confirm the two English-ability components sum to the Polish-at-home total.
- Confirm county estimates reconcile to Georgia for all three measures.
- Review missingness, margins of error, CV flags and map exclusions.
- Confirm Web Mercator static maps and WGS84 GeoJSON.
- Compare README figures with the current generated reporter brief.
- Never add ancestry, birthplace and language estimates together.
